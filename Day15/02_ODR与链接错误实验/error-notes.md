# 错误记录

完成实验时分别记录：


1. 没有可见声明时的一条关键编译错误；
   未定义标识符 "add"
2. 缺少定义或实现源文件时的一条关键链接错误；
1 个无法解析的外部命令
无法解析的外部符号 "int __cdecl add(int,int)" (?add@@YAHHH@Z)，函数 main 中引用了该符号
3. 普通函数重复定义时的一条关键链接错误；
"int __cdecl add(int,int)" (?add@@YAHHH@Z) 已经在 main.obj 中定义
"int __cdecl add(int,int)" (?add@@YAHHH@Z) 已经在 main.obj 中定义
找到一个或多个多重定义的符号
4. 每个错误的根因和最小修正。
1: 在对应头文件中增加函数声明 原因: 未在头文件中生成，导致头文件展开后仍然找不到目标函数
2: 将对应源文件添加到项目中   原因: 找不到对应源文件导致无法生成目标文件
3: 将函数定义在源文件中实现   原因: 头文件在多个文件中展开导致重定义
